# BCMX（BC Map eXtended）

Bondage Club 聊天室地图功能强化插件：本地存档、小地图、管理员传送与自由地图编辑。

## 功能

### 地图存档

- 一键保存当前聊天室地图到浏览器本地；
- 多存档管理：新建、覆盖、重命名、备注、删除；
- 导出单张地图文件或整个地图库，随时分享或备份；
- 导入插件地图文件，也支持导入 BC 原生地图字符串；
- 一键应用存档到当前地图房，应用前自动备份当前地图（最多保留 10 份）；
- 存档按玩家账号自动隔离，多账号互不干扰。

### 小地图

- 全图概览：实时显示可通行区域与所有玩家位置；
- 滚轮缩放、拖拽平移，随意查看任意局部区域；
- 玩家标记颜色跟随昵称颜色，一眼认出谁是谁；
- 坐标隐藏（捉迷藏）：一键隐藏自己的坐标与标记，其他小地图用户看不到你的位置，名字仍保留在房间列表。

### 管理员传送

- 管理员在小地图上选中任意玩家，直接传送到任意格子；
- 被传送的玩家无需安装插件，但需要处于地图视图。

### 地图编辑器

- 使用 BC 原版地块与物件素材渲染完整 40×40 地图；
- 自由拖拽、鼠标锚点缩放与整图复位，无需让角色走到目标区域；
- 地块与物件按类型快速切换，可按名称、类型或 ID 搜索；
- 支持 1～5 格画笔、橡皮、右键临时擦除、网格开关、撤销与重做；
- 关联游戏物品的素材会检查持有状态，未持有时灰显；
- 编辑结果沿用 BC 原版同步链路，仅房间管理员可用。

## 安装

### 便携远程加载器（推荐）

[![Install Loader](https://img.shields.io/badge/Tampermonkey-%E5%AE%89%E8%A3%85BCMX-245a91?labelColor=1c1c1c&logo=tampermonkey)](https://raw.githubusercontent.com/stareyeXuanyeLin/BC-MX/main/dist/BCMX.loader.user.js)

每次进入 BC 时自动获取并执行最新版核心脚本，无需手动更新。GitHub 访问不畅时会自动切换备用源。首次安装时需允许访问加载器列出的远程域名。

### 完整核心脚本

```text
https://raw.githubusercontent.com/stareyeXuanyeLin/BC-MX/main/dist/BCMX.user.js
```

手动安装，更新时需要重新获取。

请只安装上面两种中的一种，避免重复加载。

## 使用

- 进入任意启用了地图的聊天室，地图模式左侧工具栏会出现“档”按钮，用于存档管理；
- “图”按钮打开小地图，入口对地图房内所有玩家可见；
- 管理员可在小地图中选中玩家并传送；
- 管理员点击“编”按钮打开地图编辑器；编辑器与小地图互斥，打开时请先退出 BC 原版编辑模式。
